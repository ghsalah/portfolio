## ✨ Features & Highlights

- 🌑 **Ultra-Dark Obsidian Theme & Day Mode**: Built with deep obsidian background (`#060608`), glassmorphism cards, ambient radial glows, and a persistent Day/Night theme switcher (`[data-theme="light"]`).
- 🌊 **Interactive Hero Wave Canvas**: Dynamic HTML5 canvas background rendering fluid glowing wave lines that adapt stroke color dynamically depending on the active theme.
- 🍔 **Dribbble-Style 3-Line Morphing Mobile Menu**: Precision CSS 3-bar hamburger icon that morphs into a smooth "X" close symbol when clicked.
- 🎯 **Pixel-Perfect Smooth Scroll Navigation**: Target section offsets calculated dynamically to align headers right below the sticky navbar without dead space.
- 💼 **Featured Projects Showcase**:
  - **CartyFly**: Next-generation e-commerce ecosystem.
  - **MediCore**: Healthcare patient & analytics portal.
  - **TalentTrove**: Smart hiring & candidate management hub.
  - **Playground Mode**: Interactive code editor & terminal command switcher mockup.
- 🍱 **Bento-Grid Tech Stack**: Modern layout showcasing Full Stack System Design, Edge-Synced Performance, and Automation tooling.
- 📄 **Direct Resume Integration**: Instant PDF download link for `Aboobacker_salah_c_Resume.pdf`.

## ⚡ How to Run Locally

1. **Navigate to the project folder**:
   ```bash
   cd salah
   ```

2. **Serve static files**:
   You can use any local static server (Python, Node `npx serve`, or Live Server):
   ```bash
   # Option 1: Python HTTP Server
   python -m http.server 3000

   # Option 2: Node.js Serve
   npx serve .
   ```

3. **Open in browser**:
   Navigate to `http://localhost:3000` to view the live app.
